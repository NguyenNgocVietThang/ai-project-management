## Giới hạn môi trường và việc còn lại

- PostgreSQL, Redis và Celery thực tế chưa chạy trong phiên này. Test tích hợp dùng SQLite; kiểm tra browser dùng API thật với SQLite riêng và dữ liệu fixture có nhãn UI Preview. Không sử dụng database dự án hiện có.
- Chưa kiểm chứng end-to-end OAuth, gửi email, Redis/WebSocket đa tiến trình và phản hồi AI từ provider thật. Bộ test hiện có của các phần này vẫn được chạy.
- Cấu hình frontend hiện tại dùng API 127.0.0.1:8000. Khi chạy local, mở http://127.0.0.1:3000 để cookie cùng hostname. Dùng localhost với cấu hình này có thể gây vòng lặp đăng nhập. Production cần cấu hình origin/cookie/reverse proxy phù hợp.
- graphify query và graphify update . đã được thử nhưng executable lỗi “uv trampoline failed to canonicalize script path”. Thử runtime tạm cũng không tải được package do mạng bị chặn. Đã đọc chỉ mục graph.json sẵn có (3127 node / 8429 edge), nhưng graph chưa cập nhật sau sửa code. Cần khôi phục graphify rồi chạy lại graphify update .
- Cảnh báo có từ bộ test cũ: Starlette import multipart deprecated, custom event_loop fixture deprecated, một số test Auth dùng AsyncMock cho db.add đồng bộ. Đây không phải lỗi test mới; chi tiết nằm trong output pytest.
